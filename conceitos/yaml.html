YAML

Definição simples: formato textual estruturado e legível, usado para representar configurações, contratos, pipelines e metadados.

Como interpretar

YAML organiza dados por indentação. Chaves e valores descrevem propriedades; listas usam hífen. Diferentemente de JSON, não exige chaves e aspas em todos os elementos. A indentação possui significado e deve usar espaços de forma consistente.

pipeline:
  nome: ingestao_inscricoes
  versao: 1.0
  fontes:
    - tipo: csv
      caminho: dados/raw/inscricoes.csv
  validacoes:
    - campo: id_inscricao
      regra: obrigatorio
      severidade: erro

YAML, JSON e Python

YAML e JSON podem representar a mesma estrutura. JSON é nativo na biblioteca padrão do Python; YAML normalmente requer uma biblioteca como PyYAML. Ao carregar arquivos recebidos de terceiros, use yaml.safe_load, nunca construtores inseguros.

# Em ambiente local: python -m pip install pyyaml
import yaml

with open("pipeline.yaml", encoding="utf-8") as arquivo:
    configuracao = yaml.safe_load(arquivo)

assert configuracao["pipeline"]["versao"] == 1.0

Quando usar

Configuração de pipelines, contratos de dados, regras de qualidade, infraestrutura como código e parâmetros de execução que precisam ser revisados por pessoas e programas.

Cuidados

Não armazene senhas ou tokens no arquivo. Valide o schema após carregar, controle versões e teste valores ausentes, tipos inesperados e indentação incorreta.
